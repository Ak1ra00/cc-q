Your Coldcard Q, but it's a game console.

QUASAR is fan-made firmware that turns the Coldcard Q, the little Bitcoin gadget with a real keyboard and a colour screen, into a pocket arcade. It comes with three games, runs at 30 frames a second, and every pixel is drawn in C.

What is this?

Explain it like I'm five.

It turns a Bitcoin gadget into a handheld game console. That's it. That's the project.
01

This is a Coldcard Q.

It's a little computer people use to keep their Bitcoin safe. It has a screen, a proper keyboard and a memory-card slot.

02

Every gadget has a brain.

That brain is a program called firmware. It decides what happens when you switch the gadget on.

03

QUASAR is a different brain.

Put it in and the Coldcard wakes up as a game console. There's no wallet in it at all, not even one line of Bitcoin code.

04

Want the old one back?

Pop in a memory card with the official firmware and it's a normal Coldcard again in a couple of minutes.

The grown-up version: QUASAR is MicroPython's STM32 port for the Coldcard Q, with the games compiled in as a native C module and signed with the public developer key. Coinkite's own bootloader still checks and installs it. Read the security notes.

The games

Three games. One tiny screen.

Switch it on and the games wait on a neon horizon, each on a live card that plays itself. Slide between them with the arrow keys and press ENTER to play.

Install

Five steps. About ten minutes.

You install QUASAR the same way as any Coldcard update, from a microSD card. Coinkite's own bootloader does the checking and the flashing.

A Coldcard Q A microSD card (two is easier)💻 A computer☕ Ten minutes
!

Read this first. The best way to try QUASAR is on a spare Coldcard Q. If yours has ever held real money, set a fresh PIN before you install anything. Never type your real wallet PIN into firmware you haven't checked yourself, on this project or anyone else's.

When you install firmware from QUASAR's SYSTEM screen, only ever type your main PIN. A trick PIN there makes the bootloader wipe the seed, just like on the official firmware.

  1. 1

    Make your way back first.

    Download the official Coldcard Q firmware from coldcard.com/downloads, put the .dfu file on a microSD card, label it "OFFICIAL" and keep it safe. That card is how you get back to a normal Coldcard.

  2. 2

    Download QUASAR.

    Save the firmware file and copy it onto a microSD card.

    ▼ quasar-1.4.0-q1.dfuAll releases

    SHA-256 9efe94b1b1203aca5376c4f00a8db8025c0dcd1a2999a831ea3169ab9ed7e0c4

  3. 3

    Install it like any update.

    Put the card in the Coldcard, then go to

    Advanced → Upgrade → From MicroSD

    Pick quasar-1.4.0-q1.dfu and confirm. The Coldcard checks the file and flashes it.

  4. 4

    Wait out the warning. It's normal.

    Every time it starts, Coinkite's bootloader shows an "unsigned firmware" warning for about 25 seconds, because only Coinkite can sign official firmware. That's the Coldcard working properly, not a bug. Then the arcade appears.

  5. 5

    Play!

    ◀▶ pick a game, ENTER plays it, and holding POWER saves your game and switches off. The home screen always opens on the last game you played.

Going back to a normal Coldcard

Put your "OFFICIAL" card in. Pick SYSTEM → INSTALL FIRMWARE on the home screen, or hold S while you switch on to jump straight there. Choose the official .dfu and enter your main PIN. A couple of minutes later it's a Coldcard again.

Questions

Things friends ask.

Can it touch my Bitcoin?

QUASAR has no wallet code at all: no seed words, no signing, nothing. It never loads a seed, so even a bug in it can't leak one. The only time it talks to the Coldcard's secure chips is when you install other firmware, and that uses Coinkite's own upgrade code, with the bootloader doing the checking. Still, try it on a spare Coldcard if you can.

Why is there a warning every time it turns on?

The bootloader only fully trusts firmware signed with Coinkite's own key, and nobody outside Coinkite can do that. Firmware anyone else builds, this one included, is signed with the public developer key. So the bootloader shows a warning for about 25 seconds before it starts. That's the Coldcard doing its job, and no firmware can skip it.

Can I always go back?

Yes. Use SYSTEM → INSTALL FIRMWARE with the official .dfu on a microSD card, or hold S at power-on to go straight there. QUASAR never raises the bootloader's "no older firmware" limit, so it never stops you going back to an official release.

Is this made by Coinkite?

No. It's an independent fan project built on Coinkite's open-source Coldcard firmware and their MicroPython fork. Coinkite doesn't make it, support it or endorse it.

Do my high scores survive updates?

Yes. Scores, settings and saved games live in small files on the Coldcard's own storage, and new versions read the old files.

How do I know the file matches the code?

Everything is on GitHub. You can build the firmware yourself and compare it with the published file, byte for byte apart from the signature and timestamp. The security notes show how.
